# 几何数据模块

## 当前进度：V0.1-1 至 V0.1-4

`Vec3.hpp` 已实现一个三维向量：保存 `(x, y, z)`，并提供加减、数乘、点积、叉积和长度平方。

本阶段的测试在 `tests/test_vec3.cpp`。它不测试网格，而是确认后续几何计算所依赖的代数规则：

- `a·b` 的结果为标量；
- `a×b` 的结果垂直于 `a` 和 `b`，方向遵从右手定则；
- `(a×b)·c` 是标量三重积，后续 `orient3d` 就会以它为基础。

`Vertex.hpp`：每个输入点有一个稳定 `VertexId` 和一个 `Vec3` 坐标。

`Tetrahedron.hpp`：一个单元只保存四个 `VertexId`。`face_opposite(i)` 可取出与第 `i` 个局部顶点相对的三角面；其面顶点顺序已经为后续“正向四面体的外法向”预留。

`Mesh.hpp/.cpp`：唯一拥有顶点和四面体数据的对象。四面体被删除时先标记为 `inactive`，不移动数组中的其他元素。之后构造 Bowyer-Watson 空腔时，旧四面体编号仍然有效。

这三个结构按你的要求暂不加入独立行为测试。V0.1-5 的 `orient3d` 将首先验证四面体顶点顺序与面方向。
